Virtualization support not detected

Docker Desktop failed to start because virtualisation support wasn’t detected. Contact your IT admin to enable virtualization or check system requirements.

Docker Desktop이 시작되지 못한 원인은 BIOS/UEFI 설정에서 메인보드의 가상화 기술(VT-x / AMD-V)이 꺼져 있거나, Windows의 가상화 기능이 비활성화되어 있기 때문입니다.

아래 Step 1과 Step 2를 순서대로 진행하시면 해결됩니다.

Step 1. Windows 기능에서 가상화 활성화 (Windows 설정)
Windows 키를 누르고 "Windows 기능 켜기/끄기"를 검색하여 실행합니다.

아래 3가지 항목을 찾아서 체크합니다.

Hyper-V (Windows Home 버전인 경우 목록에 없을 수 있으며, 없으면 넘어갑니다)

가상 머신 플랫폼 (Virtual Machine Platform)

Windows 하이퍼바이저 플랫폼 (Windows Hypervisor Platform)
