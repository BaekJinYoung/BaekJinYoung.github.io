해결 방법 3: Node.js 및 npm 글로벌 캐시 경로 권한 초기화
만약 특정 사용자 폴더(AppData\Local\npm-cache 등)의 접근 권한이 꼬인 경우라면, 해당 캐시 폴더를 삭제하고 다시 시도하는 것이 좋습니다.

Win + R을 눌러 실행 창을 엽니다.
%LocalAppData%를 입력하고 엔터를 누릅니다.
열린 폴더에서 npm-cache 폴더를 찾아 삭제합니다.
Win + R을 누르고 %AppData%를 입력한 뒤, npm 폴더 내부의 임시 파일들을 정돈하거나 삭제합니다.
터미널을 다시 열어 npm install을 실행합니다.
