Laravel이 정상적으로 동작하고 DB 연동까지 원활하게 진행되려면 몇 가지 필수의 필수 확장 모듈을 추가로 활성화해주셔야 합니다.

지금 상태 그대로 두면 프로젝트 생성은 되더라도 문자열 처리(mbstring), 데이터베이스 연결(pdo_mysql 등), 이미지/국제화 처리(gd, intl) 과정에서 다시 Composer 에러나 런타임 에러가 발생합니다.

필수 및 권장 확장 모듈 설정
php.ini에서 아래 모듈들의 앞 세미콜론(;)을 제거하여 활성화해 주세요.

Ini, TOML
extension=curl
extension=fileinfo
extension=gd
extension=intl
extension=mbstring
extension=openssl
extension=pdo_mysql        ; MySQL / MariaDB 사용 시 필수
extension=pdo_sqlite       ; SQLite 기본 사용 시 필수
extension=sqlite3          ; SQLite 사용 시 권장
extension=zip              ; Composer 패키지 압축 해제 속도 향상
주요 모듈별 역할
mbstring: Laravel의 UTF-8 한글 및 다국어 문자열 처리에 필수적인 모듈입니다. (미활성화 시 설치 단계부터 오류 발생)

pdo_mysql / pdo_sqlite: Laravel의 Eloquent ORM 및 데이터베이스 연결을 담당합니다.

curl / zip: Composer가 패키지를 빠른 속도로 다운로드하고 압축을 풀 때 사용합니다.

intl / gd: 날짜/시간 국제화 처리 및 이미지 업로드·썸네일 생성 기능에 필요합니다.

수정 후 저장하신 뒤 laravel new project를 다시 실행하시면 에러 없이 깔끔하게 설치될 것입니다.
